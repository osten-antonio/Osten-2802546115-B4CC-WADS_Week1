# Fullstack web development: Overview

Web development is the engine behind the digital experiences we use daily, fundamentally split into what users see and the logic that powers it. At the forefront is the frontend, or client-side, where developers use HTML, CSS, and JavaScript to build the visual interface. This layer is responsible for the layout, design, and interactivity, ensuring that everything from navigation bars to complex animations feels responsive and intuitive within the user's browser.
